# pop

stop finding and copy pasting the same links everytime. press `ctrl + ;` in any input, pick with keyboard, done. everything stays local.

## install

1. clone this repo
2. open `chrome://extensions`
3. turn on developer mode (top right)
4. load unpacked → select this folder
5. pin pop to the toolbar

## use

- click the icon, add key + value (e.g. `github` → your url)
- in any form, press `ctrl + ;`, type to filter, `↑↓` to move, `enter` to paste
- export / import your snippets as json from the popup footer
