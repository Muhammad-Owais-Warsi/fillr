# Getting Started with Rust

Rust is a systems programming language that runs blazingly fast, prevents segfaults, and guarantees thread safety.

## Why Rust?

1. **Memory safety** - No null pointer exceptions
2. **Concurrency** - Safe parallel programming
3. **Speed** - Comparable to C/C++
4. **Tooling** - Cargo is amazing

## Installation

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

## Your First Program

```rust
fn main() {
    println!("Hello, world!");
}
```

That's it! You're ready to start your Rust journey.
